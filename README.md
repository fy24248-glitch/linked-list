# Singly Linked List (Python)

A from-scratch implementation of a singly linked list data structure with common operations.

## Features
- `append(value)` — add to the end
- `prepend(value)` — add to the start
- `delete(value)` — remove first matching node
- `find(value)` — search for a value
- `reverse()` — reverse the list in place
- `to_list()` — convert to a Python list for easy printing
- `__len__` and `__str__` support

## How to run
```bash
python linked_list.py
```

## Example output
```
List: [1, 2, 3, 4]
Length: 4
Found 3? True
After deleting 2: [1, 3, 4]
Reversed: [4, 3, 1]
```

## Why this project
The linked list is one of the most fundamental data structures in DSA interviews — understanding node references, pointer manipulation, and in-place reversal here builds intuition for trees and graphs later.
